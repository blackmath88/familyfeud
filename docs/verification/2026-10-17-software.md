# Software verification — 2026-10-17

Scope: PR #3, `origin/main` through the review branch head. This record covers software checks only; the physical HDMI/60fps gate remains pending.

## Independent review

Codex CLI review mode inspected the complete PR diff at initial head `fd9596dae841536be164b0e46b4d92bad8c2927d` in an enforced `read-only` sandbox with approvals disabled. It reported eight P2 findings: live audio activation, mute propagation, reset lifecycle/reconnection, face-off rotation, failed-steal rotation, duplicate-overlay lifetime, malformed alias validation, and multi-commit command delivery. All eight were corrected and covered by focused or browser checks before the final exact-head review.

A follow-up read-only review at head `1a1cccb574412a7ed29289cf91e1f919cd8fa826` found four further undo/reset edge cases: replacement-game history, event sequence reuse, revised boundary persistence, and discarded duplicate status. These were corrected, with focused reducer tests and browser coverage added before reviewing the resulting exact head again.

The next exact-head review at `a2ac8ece8a9daa9aa9d19451a05c6c2d158775f3` found that the TV route still mounted authoritative host storage and that missed round-end answers lacked the specified sequential presentation. The board route is now provider-free and reads only a separate game ID; the smoke test records storage access and fails if it reads `fq:active-game`. Missed answers use a reduced-motion-safe stagger only on a fresh transition into `roundEnd`.

Review of head `0124365660710c22110c5a1a245fbdc3fd4bb487` identified inconsistent player rotation after a face-off miss, SPA fallback for unknown API paths, and an ineffective manual command-bus trigger. Face-off misses now rotate the answering player, `/api/*` misses return a JSON 404 without consulting assets, and the unused manual trigger was removed without delivering any command.

Review of head `6ba152eda69272c5faebbd376cc36ec52c61e4e3` found that the host's `A`/`B` shortcuts assigned control instead of selecting the first face-off responder, and that a correct answer which ended a round lost its reveal feedback. Keyboard and visible controls now distinguish responder selection from forced control. Round-win events carry the final answer rank when applicable, allowing the board to complete its reveal animation and ding before the win feedback.
